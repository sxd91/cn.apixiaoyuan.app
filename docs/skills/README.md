# Skills 目录说明

本目录存放可跨对话复用的技能文档（skill）。每个 skill 是一份自包含的规范，可直接贴进任意对话开头作为约束，也可作为工程内的长期参考。

## 目录

| 文件 | 用途 | 体量 | 适用场景 |
|---|---|---|---|
| `tool-call-discipline.md` | 工具调用规范 · 完整版 | 160 行 | 人查阅、工程内长期参考、排查工具失败时对照 |
| `tool-call-discipline-compact.md` | 工具调用规范 · 精简注入版 | 56 行 | 直接贴进任意对话开头当约束 |

## 使用方式

**方式一 · 注入对话开头**
把 `tool-call-discipline-compact.md` 的全文贴进对话最前，作为本次会话的工具调用约束。适合：新开对话、换设备、换工具集时。

**方式二 · 工程内参考**
工具调用失败时，对照 `tool-call-discipline.md` 第五节「失败排查流程」按错误类型定位根因。

**方式三 · 随工程分发**
两个文件都在 git 仓库内，clone 后即可见。新协作者或新对话实例直接读 `docs/skills/README.md` 找到入口。

## 维护约定

- 新增 skill：在本目录落独立 `.md`，命名用 `kebab-case`，并在本 README 的目录表里补一行。
- 精简注入版与完整版必须成对出现：完整版讲清「为什么」，精简版只讲「怎么做」。
- 每条规范应可追溯到一次真实失败。凭空设想的规则不写进 skill。
